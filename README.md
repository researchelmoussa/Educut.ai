# EduCut.ai website

Static site. `index.html` is the landing page and the full application
(assessment, consultation booking, sign-in, admin/company/learner
workspaces). The public catalogue pages are plain HTML generated from the
Supabase catalogue.

## Public pages

| URL | Source |
| --- | --- |
| `/` | `index.html` |
| `/academies/` | generated — academy hub |
| `/academies/<slug>/` | generated — one page per academy, with its courses |
| `/ai-learning-paths/` | generated — learning paths + how the assessment works |
| `/contact/` | generated — consultation, catalogue request, contact emails |

Private areas stay inside `index.html` as fragment routes
(`/#/admin/…`, `/#/company/…`, `/#/academy/…`) and are not separate pages.

## Updating the generated pages

1. Run the queries in `scripts/export-catalogue.sql` in the Supabase SQL
   editor and paste the results into `data/academies.txt` and
   `data/courses.txt`.
2. `node scripts/build-pages.mjs` (Node 18+, no dependencies).
3. Commit the regenerated files.

The build also rewrites `assets/site.css` (extracted from the landing CSS in
`index.html`) and the footer block in `index.html` between the
`site-footer` markers. Edit `assets/pages.css` for styles used only by the
generated pages.

Academy URLs are derived from academy names, so renaming an academy in the
admin workspace changes its URL until the pages are rebuilt.

## Hosting

Every page is a folder with an `index.html`, so any static host serves the
clean URLs without rewrite rules.

## Crawling and indexing

`robots.txt` and `sitemap.xml` are generated by the build (22 public URLs).
`404.html` is a `noindex` error page; most static hosts serve it
automatically. Everything behind `/#/admin`, `/#/company` and `/#/academy`
lives in the URL fragment and is never indexed as a separate page.

Recommended host redirects (301): `http://` → `https://`,
`www.educutai.com` → `educutai.com`, and `/academies/<slug>` →
`/academies/<slug>/` (most static hosts add the trailing slash themselves).

## Languages

English only for now; French is prepared as the next language
(`content/i18n.mjs`). `node scripts/build-pages.mjs --i18n-kit` exports
every page-level string to `content/i18n/translation-kit.json`
(phase 1: core pages and academies; phase 2: course programmes). A
translated page is announced with `hreflang` only after it exists and is
mapped in `ALTERNATES`; the build refuses mappings to missing pages.

## After each deployment

1. `node scripts/indexnow.mjs` notifies Bing and other IndexNow engines of
   every URL in `sitemap.xml` (or pass paths, e.g. `/academies/rag-systems/`;
   `--dry-run` shows the request). The key file
   `47a47702eb335d7320412390b1ffdb91.txt` must be deployed at the site root.
2. Google: submit or resubmit `https://educutai.com/sitemap.xml` in Search
   Console; use URL Inspection → Request indexing for important changes.

## Monitoring

Monthly SEO + GEO routine: `MONITORING.md`, with `scripts/monthly-report.sql`
(read-only conversion queries) and `seo/geo-prompts.csv` (20 AI-assistant
test questions) + `seo/geo-log-template.csv`.
