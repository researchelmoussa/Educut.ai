Score per snippet: omission vs. hallucination, by method

For each snippet, every gold article the method missed is an omission (−1), every predicted article not in gold is a hallucination (+1), and every correctly predicted article counts 0. Score = hallucinations − omissions. Example: gold = {4, 5}, method = {7} → 2 omissions + 1 hallucination = −1. An answer of 0 is Class 0 (“no violation detected”): the method predicts nothing, so it has 0 predictions and 0 hallucinations, and every gold article of that snippet is an omission. Example: gold = [5], method = 0 → omission −1, prediction 0, hallucination 0 → score −1. Bars: yellow below zero = omitted articles; blue above zero = correct articles (0 points, shown for context); orange stacked on top = hallucinated articles; black dot = net score. Expected hallucination per sub-level (6 methods pooled) · Structure AStructure B

If a snippet belongs to a given sub-level, what hallucination rate (FDR) should we expect, whatever the method? The 6 methods are pooled. This table follows the A / B switch. In each level, the sub-level with the highest expected FDR is in orange and the lowest in blue; "Beyond chance?" says whether the 95% interval excludes the overall FDR. Precision, FNR and TPR of the pooled counts are given for context. Formulas are under the worked example.

How it is calculated (example: Expression, Structure A)

  1. Select the snippets of the sub-level using snippet_tags.csv: 23 snippets are tagged Expression.
  2. Pool the 6 methods. On those 23 snippets, count every article each method predicted (144 in total) and how many of them are not in the snippet's gold label (101 hallucinations). An answer of 0 (Class 0) predicts nothing, so it adds nothing to either count.
  3. Expected hallucination = hallucinations ÷ predicted articles = 101 ÷ 144 = 70.1%.
  4. Compare with the overall rate of the structure, all 887 snippets and 6 methods: 2600 ÷ 4139 = 62.8%. Difference = 70.1 − 62.8 = +7.3 points; ratio = 70.1 ÷ 62.8 = ×1.12.
  5. 95% interval: draw the 23 snippets again at random with replacement, recompute the rate, repeat 2000 times, and keep the middle 95% of the results (54.5% to 81.5%). Whole snippets are redrawn because the articles of one snippet are not independent. The interval contains 62.8%, so the difference is not beyond chance: with so few snippets, +7.3 points could be chance.

How it is calculated (example: Expression, Structure B)

  1. Select the snippets of the sub-level using snippet_tags.csv: 23 snippets are tagged Expression.
  2. Pool the 6 methods. On those 23 snippets, count every article each method predicted (110 in total) and how many of them are not in the snippet's gold label (74 hallucinations). An answer of 0 (Class 0) predicts nothing, so it adds nothing to either count.
  3. Expected hallucination = hallucinations ÷ predicted articles = 74 ÷ 110 = 67.3%.
  4. Compare with the overall rate of the structure, all 887 snippets and 6 methods: 2709 ÷ 4095 = 66.2%. Difference = 67.3 − 66.2 = +1.1 points; ratio = 67.3 ÷ 66.2 = ×1.02.
  5. 95% interval: draw the 23 snippets again at random with replacement, recompute the rate, repeat 2000 times, and keep the middle 95% of the results (47.1% to 79.5%). Whole snippets are redrawn because the articles of one snippet are not independent. The interval contains 66.2%, so the difference is not beyond chance.

Formatting sub-levels are flags, so a snippet can count in several of them. Documented has a single snippet and no method predicted anything for it. Computed by analysis/gdpr_bench_structures/expected_by_subtype.py (fixed random seed, so the intervals are reproducible).
